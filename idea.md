## GameSlot

### Main problem

Friends don’t communicate their availability efficiently, making it difficult to find a common time to meet and play board games.

### MVP

- User accounts and friend group creation
- Shared group availability calendar
- Marking available time slots (day + starting hour)
- Host selects and confirms a game session slot
- Host sets the meeting location
- Notifications for confirmed sessions
- Notifications when someone joins a time slot the user is already in (to reduce spam)

### What does NOT come in MVP

- In-app chat / messaging system
- Board game library and recommendations
- Automatic game suggestions based on player count or preferences
- Integration with Google Calendar / Apple Calendar
- Voting system for choosing games or dates

### Success criteria

- Users complete the core flow (availability → match → confirmation) without major confusion
- At least a few game sessions are successfully scheduled and used in real situations
- Users continue using the app beyond the first try (basic repeat usage)
